- `הפועל ת"א גברה 78:80 על מקסימה רומא` — entities none, and `news` (see 2). Rated low.
- `חי ממשחק ההכנה: אולימפיאקוס - מכבי תל אביב 35:35 (מחצית)` — entities none, `news` (#218 fixed the evidence for NEW ingestion; this row predates it). Rated low.
- `אקס מכבי ת"א חושב בגדול` — entities none. Rated low.

The abbreviated club is the #190/#194 ambiguous-club deadlock: `מכבי ת"א` sits in the registry under both football and basketball, and a scoreline of 87:92 does not break the tie today. This is the single largest theme and the one the old stratified sample could not resolve (basketball rows were under-weighted 13x).

### 2. Event type — one missing verb, three wrong events (5 rows)

### 3. The one push was wrong (push precision 0/1)

`"פורטלנד הייתה צריכה לבנות על דני אבדיה, העתיד שלו בקבוצה הסתבך"` — stored **`major_trade`**, pushed. Rated **low**. It is an opinion column about Deni's situation, not a trade. The push-severity rule (#192) requires a current development; a `major_trade` event that is really `analysis`/`opinion` slips past it because the event type is the lie. This is a classification error that reached the phone.

### 4. Tennis — the sport is level -1, so only tagged events surface (4 false hides, 2 rated feed+)

## What this says

- The recall failure is **facts, not rules**, exactly as #208 concluded: 12 of 18 false hides have a wrong or missing fact (entity, event type, sport) and the relevance rules then act correctly on the wrong fact.
- Two are one-liners in the evidence lists: `גבר/גברה/גברו` as a result verb; `אליפות ארה"ב הפתוחה` as a Slam.
- The push miss is a classification miss (`major_trade` on an opinion piece), not a push-rule miss.
- Football: 3 false hides, all rated low. The engine's football scope is right for Guy.
