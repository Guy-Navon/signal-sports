# scripts

- `check.ps1`: run the same checks as CI locally on Windows (`-Backend` / `-Frontend` to limit).
- `dev.sh`: Linux dev commands (codespace, devcontainer, host): `api`, `web`, `test`, `check`, `gate`, `env`; see its header.
- `worker.ps1`: start/stop/status of the scheduler worker on the Windows PC (`-Status` first).
- `generate_audit_report.py`: generate the repository audit report.
